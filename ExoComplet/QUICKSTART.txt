3. TEST RAPIDE JOUR 2 (SafeReader):

   # Lancer le programme
   ./safereader

   # Menu: 1 (Générer)
   Nom: test.safe
   Contenu: Ceci est un test SafeReader!

   # Menu: 2 (Valider)
   Fichier: test.safe
   => Doit afficher "FICHIER VALIDE"

   # Menu: 3 (Corrompre)
   Source: test.safe
   Sortie: bad.safe
   Mode: 4

   # Menu: 2 (Valider le fichier corrompu)
   Fichier: bad.safe
   => Doit détecter "CHECKSUM INVALIDE"

────────────────────────────────────────────────────────────────────────────

4. TEST RAPIDE JOUR 3 (CryptFile):

   # Créer fichier secret
   echo "Message secret à chiffrer!" > secret.txt

   # Lancer CryptFile
   ./cryptfile

   # Menu: 1 (Chiffrer)
   Source: secret.txt
   Sortie: secret.enc
   Clé: password123

   # Menu: 2 (Déchiffrer)
   Source: secret.enc
   Sortie: decrypted.txt
   Clé: password123

   # Vérifier
   cat decrypted.txt
   => Doit afficher le message original

   # Menu: 3 (Test symétrie)
   Fichier: secret.txt
   Clé: password123
   => Doit confirmer symétrie OK

ÉTAPE 1: Comprendre la structure
---------------------------------
Ouvre chaque .cpp et identifie:

🔧 DÉPANNAGE RAPIDE
════════════════════════════════════════════════════════════════════════════

ERREUR: "Impossible d'ouvrir le fichier"
  → Vérifie que le chemin est correct
  → Vérifie les permissions du fichier
  → Utilise "./" pour les fichiers locaux

ERREUR: "Pas assez de mémoire"
  → Le fichier est peut-être trop gros
  → Vérifie avec "ls -lh fichier.bin"

ERREUR: Compilation échoue
  → Vérifie que g++ est installé: g++ --version
  → Utilise: g++ -std=c++11 ExoXX.cpp -o exo

Le programme plante sans message
  → Compile avec debug: g++ -g ExoXX.cpp -o exo
  → Lance avec gdb: gdb ./exo
